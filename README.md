# Torneo VGM

Bracket 1vs1 de canciones de videojuegos para votar con amigos, cada uno desde su PC.

- Crea una sala, pasa el código de 4 letras o el enlace a tus amigos.
- Elige tamaño (16, 32, 64 o 128), escuchad los dos temas en YouTube y votad.
- La lista de canciones se puede editar en la pestaña *Canciones*.
